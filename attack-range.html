Modules

Sixteen modules, in recommended order. Each one teaches a topic, walks through the attack, gives you labs for that exact topic, and ends with a defence you build.

How a module works

Sixteen modules take you from threat modeling to incident response. Each one is theory, then how the attack works, then hands-on labs for that topic, then a defence you build for real.

  1. Theory What the vulnerability class is, why it exists, and the research behind it.
  2. How the attack works The attack step by step, with example payloads, before you touch a target.
  3. Hands-on lab A live vulnerable target runs right in the page. Exploit it until it leaks a FLAG{…}, then paste the flag to clear the lab. Hints, a live coach and the full solution are there if you get stuck.
  4. Build the defence A real project you build on your own machine, hardening the reference app Courier, with a "done when" checklist.

What you build: Courier

The projects all harden one reference app, Courier, an agent that reads a support inbox, searches a knowledge base, and writes to a CRM, so by the end you have one defended system for your portfolio. Each defence below opens the module where you build it.
